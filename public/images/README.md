# Инструкция по добавлению собственных фотографий

Все фотографии сайта хранятся в этой папке: `public/images/`.

## Имена файлов и где они отображаются на сайте:

1. **Главный экран (Hero Section)**:
   - Имя файла: `hero.jpg`
   - Рекомендуемая ориентация: Горизонтальная (16:9 или 16:10, мин. 1920x1080px).
   - Содержание: Всадники на фоне гор и озера, живописный простор.

2. **Раздел «О туре и озере Сон-Куль» (About Us)**:
   - Имя файла: `yurt-camp.jpg` (юрта / лагерь кочевников, вертикальная или 4:5).
   - Имя файла: `guide-horse.jpg` (портрет проводника, всадника или лошади крупным планом, вертикальная или 4:5).

3. **Карточки туров (Tour Packages)**:
   - `tour-express.jpg` — обложка для тура «Сон-Куль Экспресс (3 дня)».
   - `tour-classic.jpg` — обложка для тура «Классический Сон-Куль (5 дней)».
   - `tour-grand.jpg` — обложка для тура «Большая экспедиция (7 дней)».
   - Рекомендуемая ориентация: Горизонтальная (16:9 или 4:3).

4. **Галерея (Gallery)**:
   - `lake-sunset.jpg` — закат / вечернее озеро.
   - Вы также можете добавить новые файлы (например, `photo1.jpg`, `photo2.jpg`) и подключить их в файле `src/components/Gallery.tsx`.

## Как заменить фото на свои:
1. Подготовьте ваши снимки в формате `.jpg` или `.png`.
2. Оптимизируйте размер (рекомендуемый вес файла: 200–800 КБ для быстрой загрузки сайта).
3. Переименуйте ваши снимки в соответствии со списком выше (например, ваше главное фото переименуйте в `hero.jpg`).
4. Скопируйте файлы в папку `public/images/`, заменив существующие.
5. Запустите сборку `npm run build` или отправьте изменения в ваш GitHub-репозиторий — Netlify автоматически обновит сайт!
